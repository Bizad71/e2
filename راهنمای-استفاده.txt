راهنمای اجرا و شخصی‌سازی

۱) فایل ZIP را استخراج کن.
۲) برای تست روی کامپیوتر می‌توانی با یک وب‌سرور محلی اجرا کنی؛ برای مثال در پوشه فایل‌ها دستور زیر:
   python -m http.server 8000
   سپس در مرورگر برو به http://localhost:8000
۳) برای گوشی، فایل‌ها را روی هاست HTTPS مثل GitHub Pages قرار بده و لینک سایت را با گوشی باز کن. برای نصب مثل اپ، از گزینه Add to Home Screen استفاده کن.

فایل words.json منبع واژه‌هاست. ساختار هر مورد:
{
  "word": "hello",
  "audio": "audio/hello.mp3",
  "examples": [
    {"sentence": "Hello, how are you?", "translation": "سلام، حالت چطور است؟"}
  ]
}

تلفظ آفلاین:
- برای هر واژه فایل MP3 داخل پوشه audio قرار بده و مسیر آن را در فیلد audio بنویس.
- اولین بار که فایل صوتی در حالت آنلاین پخش/دریافت شود، Service Worker آن را در Cache مرورگر ذخیره می‌کند و دفعات بعد از همان حافظه پخش می‌شود.
- باید سایت با HTTPS یا localhost باز شود؛ باز کردن مستقیم index.html با file:// برای ذخیره آفلاین کافی نیست.
- اگر audio خالی باشد، از صدای داخلی مرورگر به‌عنوان جایگزین استفاده می‌شود؛ این صدا ممکن است آفلاین کار کند یا نکند و ذخیره‌شدنش تضمین‌شده نیست.

چرخ واژگان با لمس یا کشیدن حرکت می‌کند. انتخاب واژه جمله نمونه بعدی را نشان می‌دهد. با دکمه «جمله جدید» نمونه بعدی همان واژه نمایش داده می‌شود. ترجمه با دکمه خودش باز و بسته می‌شود.
